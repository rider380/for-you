Preview:

To publish on GitHub Pages:
1. Extract this ZIP.
2. Open your GitHub repository.
3. Upload index.html and the photos folder (upload the files inside it too).
4. Commit the changes.
5. In Settings > Pages, choose Deploy from a branch, main, / (root), if not already set.
6. Open the GitHub Pages URL after the build finishes.

Important:
Keep the photos folder and index.html together. Do not rename the photo files unless you also update the paths in index.html.
